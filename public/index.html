How access works
  1. Create each person on the People tab with a username and a temporary password. They choose their own password at first sign-in.
  2. Put people in groups, and tick what they may do: view, download, copy, edit.
  3. Access can be set on a single file, on a folder (it covers everything inside), for a person or for a group. Permissions from all of these add up.
  4. A person only ever sees the files granted to them. Requests and comments arrive on the Requests tab. An approved edit request lets the person save one change; to edit again they must ask again.
  5. People with the Admin role see every file and manage everything.
